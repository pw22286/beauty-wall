考虑到**国内网络环境**和**访问速度**，接入一些国内有 CDN 或者访问友好的平台是非常必要的。

除了 **Bing**（必应），以下是几个非常适合国内用户的壁纸来源建议，涵盖了**综合、二次元、摄影**等不同垂直领域，并且大部分都有现成的（官方或非官方）API 可用。

### 1. Bing 每日壁纸 (必选)
这是国内壁纸软件的标配。

*   **特点**：
    *   **极速**：微软国内服务器，秒开。
    *   **质量高**：每天一张，全球摄影精选。
    *   **有故事**：每张图都有版权信息和背后的故事（Copyright 字段）。
    *   **省心**：不用用户配置，开箱即用。
*   **API 简述**：
    Bing 官方提供了非常简单的 JSON 接口：
    `https://cn.bing.com/HPImageArchive.aspx?format=js&idx=0&n=1`
    *   `idx`: 0 是今天，1 是昨天，以此类推。
    *   `n`: 获取数量。
    *   拿到 `url` 后加上 `https://cn.bing.com` 前缀即可。

### 2. 360 壁纸 / 鸟壁纸 (国内综合类首选)
虽然 360 这个品牌口碑一般，但它的壁纸库是目前国内**最全、分类最细、CDN 最快**的之一。很多国产壁纸软件其实都是调用的 360 的接口。

*   **特点**：
    *   **分类全**：风景、美女、动漫、游戏、汽车、4K。
    *   **速度快**：国内 CDN。
    *   **接口开放**：虽然没有官方文档，但接口非常透明，Github 上有很多现成的封装。
*   **API 参考**：
    `http://wallpaper.apc.360.cn/index.php?c=WallPaper&a=getAppsByOrder&order=create_time&start=0&count=1&cid=36`
    *   `cid`: 分类 ID（例如 36 是 4K，6 是美女，5 是游戏）。

### 3. NASA APOD (每日天文图)
这是一个非常有格调的来源，虽然服务器在国外，但通常访问不慢，且图片质量极高（甚至有 8K、TIFF）。

*   **特点**：
    *   **逼格高**：每天一张宇宙深空摄影。
    *   **教育意义**：适合极客、天文爱好者。
*   **API**：
    NASA 官方提供开放 API，申请一个 Key 就能用。
    `https://api.nasa.gov/planetary/apod?api_key=DEMO_KEY`

### 4. Pexels (Unsplash 的替补)
Pexels 和 Pixabay 是 Unsplash 的主要竞争对手。

*   **特点**：
    *   **版权友好**：CC0 协议。
    *   **访问性**：在某些地区，Pexels 的访问速度比 Unsplash 稍好（不绝对，视网络情况）。
    *   **官方 API**：提供完善的官方 API。

### 5. 动漫二次元类 (针对年轻用户)
既然你接了 Wallhaven，说明你的用户群体可能有二次元需求。国内二次元图源比较分散，但有几个方向：

*   **Bilibili (B站)**：
    *   B站其实有很多官方壁纸活动，或者通过搜索接口抓取高赞的专栏图片。但这需要一定的爬虫技术，且要注意防盗链。
*   **Konachan / Yande.re**：
    *   **特点**：极其硬核的二次元图站。
    *   **缺点**：**R18 内容极多**。如果你接入这个，必须默认开启极其严格的过滤，否则你的 App 可能会被下架或违规。建议作为“隐藏功能”或“高级源”。
*   **Pixiv (P站)**：
    *   **特点**：质量最高。
    *   **缺点**：国内无法直连（需要代理），且 API 获取难度大（反爬严格）。**不建议 MVP 阶段接入**。

### 6. 随机图源 (One API / 搏一搏)
国内有很多开发者维护的“随机图 API”，比如：

*   **保罗 API / 樱花 API**：
    *   这些 API 通常聚合了各种二次元或风景图。
    *   **优点**：接口极其简单，就一个 URL，访问就跳转图片。
    *   **缺点**：稳定性依赖于个人开发者，可能哪天就挂了。

### 3. 如何降低 Wallhaven 的“劝退感”？

对于那些想用 Wallhaven 但不想折腾的用户，你可以做一些**“中间层优化”**（技术含量稍高，作为 MVP 后期考虑）：

1.  **内置教程 (WebView)**：
    在填 Key 的界面，放一个“如何获取 Key”的按钮。点击后弹出一个小的 WebView，直接加载 Wallhaven 的 API Key 页面，并高亮显示 Key 的位置。让用户登录后复制粘贴即可。

2.  **客户端缓存 (Rate Limiting)**：
    在你的 App 代码里写死逻辑：来源于 Wallhaven 的请求，强制间隔不能低于 30 秒。这样即使你用自己的 Key 给免费用户用，也能极大程度防止 Key 瞬间爆掉。

### 1. 公共图源（免费版主力，开箱即用）

这部分是留住用户的关键，必须**量大管饱**且**速度快**。

#### **A. Bing 每日壁纸 (必选)**
*   **定位**：每日打卡，极简风格。
*   **接口**：微软官方接口，无鉴权，无限制。
*   **展示文案**：`必应每日精选`

#### **B. 360 壁纸 / 鸟壁纸 (核心主力)**
*   **定位**：替代 Unsplash/Wallhaven 的**分类图库**。
*   **接口特点**：HTTP 请求，无需 Key，国内 CDN，分类极全（4K、动漫、风景、美女）。
*   **实现方式**：
    你不需要告诉用户这是“360壁纸”，你可以把它的分类包装成独立的“频道”：
    *   `频道：4K 风景` -> 对应 360 的 `cid=36` (4K)
    *   `频道：二次元` -> 对应 360 的 `cid=26` (动漫)
    *   `频道：萌宠` -> 对应 360 的 `cid=14` (萌宠)
*   **接口参考**：
    ```
    http://wallpaper.apc.360.cn/index.php?c=WallPaper&a=getAppsByOrder&order=create_time&start=0&count=1&cid={分类ID}
    ```
    *(这个接口非常稳定，是国内很多壁纸软件的幕后功臣)*

#### **C. 随机二次元 (可选)**
*   **定位**：满足年轻用户的“抽卡”心理。
*   **接口**：使用一些公益的 API，或者直接解析 B 站/Pixiv 的镜像站（注意防盗链）。
*   **推荐**：直接用 360 的动漫分类最稳，或者找一些 GitHub 上维护的长期稳定的随机图 API。

### 3. 商业模式与功能划分（修订版）

既然图源上做了切分，付费点就可以设计得更自然：

| 功能 | 免费版 (Free) | 专业版 (Pro) |
| :--- | :--- | :--- |
| **公共图源** | ✅ Bing, 360全分类 | ✅ Bing, 360全分类 |
| **私有图源** | ❌ **不可用** (或者只能试用默认参数) | ✅ **解锁 Wallhaven / Unsplash** (填入 Key 后可用) |
| **自定义参数** | ❌ 仅限默认分类 | ✅ 自定义关键词、分辨率、纯净度 |
| **刷新频率** | ⚠️ 限制最低 1 小时 | ✅ 解锁 15分钟、30分钟 (高频刷新) |
| **多显示器** | ❌ 所有屏幕同壁纸 | ✅ 每个屏幕不同源/不同图 |
| **历史记录** | ❌ 只能看当前 | ✅ 本地保存最近 20 张 |

### 4. 为什么这个方案更好？

1.  **彻底规避 API 风险**：你不需要维护任何 Key，用户用自己的 Key 封了也是封他自己的，与你无关。
2.  **降低门槛**：小白用户下载软件，默认是 Bing 或 360 风景，**直接就能用**，不需要注册任何东西，留存率高。
3.  **筛选核心用户**：愿意去申请 Key 的用户，通常也是愿意付费 Pro 版的用户（Power User）。
4.  **教育用户**：通过这种方式，用户会明白“高质量服务是有成本的（要么花钱，要么花时间折腾）”。

### 总结

你的 App 现在的“来源管理”里，预设几个**无需 Key** 的来源（底层走 Bing 和 360），把它们起名为：
*   `每日精选 (Bing)`
*   `4K 风景 (公共)`
*   `二次元 (公共)`

然后把 Wallhaven 和 Unsplash 标记为：
*   `Wallhaven (需配置)`
*   `Unsplash (需配置)`

这样就完美解决了“国内访问”、“API 限制”和“用户门槛”的三角矛盾。
